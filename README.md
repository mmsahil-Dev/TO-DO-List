✨ My TO-DO List Web App — Simple, Clean & Smart ✨
Hey there! 👋
This is a little project I built using plain HTML, CSS, and JavaScript — no frameworks, no libraries, just the pure magic of handwritten code. It's a clean and simple To-Do List app where you can add tasks, check them off when you're done, delete them if needed, and best of all — your tasks won’t disappear even if you refresh the page. 😌💾

💡 What This App Can Do
📝 Add tasks — Just type and hit "Add"
✅ Mark them as done — Click on a task to strike it out
🗑️ Delete tasks — Remove anything you’re done with
💾 Memory power! — Tasks stay saved in your browser using localStorage
✨ No server needed — It all works right in your browser

🌐 Live Preview
Wanna try it out? Just open the index.html file in your browser and boom — your personal little task manager is live and ready to go!
(If I upload it online, I’ll share the link here too 🫶)

🧠 How It Works (In Simple Words)
You add a task → it shows up in the list

You click it → it’s marked done

You delete it → it's gone

You reload the browser → everything is still there 😍
Thanks to localStorage — your list remembers everything, like a little brain in your browser 🧠✨
